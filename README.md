**إتقان (Itqan)** هو تطبيق ويب متكامل ثنائي اللغة (العربية بالاتجاه من اليمين لليسار RTL والإنجليزية LTR) لتخطيط ومتابعة واستدامة حفظ القرآن الكريم ومراجعته وفق خوارزميات التكرار المتباعد (Spaced Repetition).

يعتمد التطبيق على المنهجية التأصيلية الراسخة للحفظ ثلاثي الأركان (**السبق**، **السبقي**، و**المنزل**)، مع جدول ذكي قابل للتكيف، ونظام تنبيهات يومية متطور، وخريطة تفاعلية للمصحف الشريف (604 صفحة / 114 سورة).

## ✨ المميزات الرئيسية | Key Features

### 1. لوحة المتابعة الإحصائية (Progress Dashboard)
* **مؤشرات المصحف الحية (Live Mushaf Metrics):**
  * حساب عدد الصفحات المحفوظة بدقة (من أصل 604 صفحة من مصحف المدينة النبوية).
  * حساب عدد الآيات المحفوظة (من أصل 6,236 آية).
  * النسبة المئوية لإنجاز المصحف الشريف.
  * عدّاد أيام الالتزام المتتالية (Active Streaks).
* **قائمة الورد اليومي (Today's 3-Tier Wird Checklist):**
  * متابعة فورية وتسجيل بنقرة واحدة لأركان الورد الثلاثة: الحفظ الجديد (**السبق**)، والربط القريب (**السبقي**)، والمراجعة الدورية البعيدة (**المنزل**).
* **مخطط النشاط لـ 14 يوماً (14-Day Activity Chart):**
  * رسم بياني مرئي يقارن حجم الحفظ الجديد مقابل المراجعة خلال الأسبوعين الماضيين.
* **تنبيهات المراجعة المستحقة (Due Revision Alerts):**
  * إبراز السور التي حان موعد مراجعتها العاجلة بناءً على مستوى ثبات الحفظ.

---

### 2. مُنشئ خطط الحفظ المخصصة (Custom Plan Builder)
* **نطاق حفظ مرن (Flexible Scope Selection):**
  * إنشاء خطة للمصحف كاملاً (30 جزءاً)، أو نطاق أجزاء محدد، أو نطاق سور، أو تحديد مخصص لسور بعينها.
* **اتجاه الحفظ وترتيبه (Order & Direction):**
  * الحفظ بالترتيب التصاعدي (من الفاتحة إلى الناس) أو العكسي (من الناس إلى الفاتحة، بدءاً من جزء عمّ).
* **تحديد الوتيرة اليومية (Custom Daily Pace):**
  * تحديد الهدف اليومي حسب: عدد الصفحات/يوم، أو عدد الأسطر/يوم (معيار 15 سطراً للصفحة)، أو عدد الآيات/يوم.
  * تحديد أيام الحفظ الأسبوعية (5، أو 6، أو 7 أيام في الأسبوع).
* **توقع زمني حي وجدولة ذكية (Live Forecast & Smart Rescheduling):**
  * احتساب معالم الخطة بدقة (السور، الآيات، أرقام الصفحات، وعدد أيام الدراسة المطلوبة).
  * تاريخ الانتهاء المتوقع، مع دعم إعادة الجدولة بنقرة واحدة عند التأخر عن الورد.

---

### 3. مساحة الورد اليومي ثلاثي الأركان (Daily Wird Workspace)
* **مساحة مخصصة للإنجاز اليومي:**
  * **السبق (Sabaq):** الحفظ الجديد اليومي وتثبيته.
  * **السبقي (Sabqi):** ربط المحفوظ القريب (آخر 5 إلى 20 صفحة تم حفظها مؤخراً).
  * **المنزل (Manzil):** المراجعة التراكمية البعيدة للحفاظ على ثبات المحفوظ القديم وعدم تفلته.
* **سجل الجلسات المفصل (Session Ledger):**
  * توثيق السورة، ونطاق الآيات، والصفحات المنجزة، والمدة الزمنية المستغرقة.
  * تقييم جودة التسميع، مع حقل لإضافة الملاحظات والمتشابهات اللفظية.

---

### 4. دورات المراجعة المتباعد الذكية (Spaced-Repetition Revision)
* **محرك قياس الثبات والتكرار التكيفي (Adaptive Retention Engine):**  
  يقوم كل تسجيل مراجعة بتحديث درجة ثبات السورة (`retentionScore`)، والفاصل الزمني بالأيام (`intervalDays`)، وتاريخ المراجعة القادمة (`nextReviewAt`) وفق تقييم التسميع:
  * 🟢 **متقن (Mutqin):** يضاعف الفاصل الزمني (يصل إلى 30 يوماً) ويرفع تقييم الثبات.
  * 🟡 **جيد (Good):** زيادة معتدلة في الفاصل الزمني.
  * 🔴 **يحتاج تثبيت (Needs Review):** يعيد الفاصل الزمني إلى يوم واحد ويضع السورة في قائمة المراجعة العاجلة لليوم.
* **حاسبة ختمة المنزل (Manzil Khatmah Calculator):**
  * تقسيم تلقائي لجميع الصفحات المحفوظة على دورات مراجعة منتظمة قابلة للتخصيص (خلال 7، أو 10، أو 14، أو 30 يوماً).

---

### 5. خريطة السور والأجزاء (Quran Map & Inspector)
* **قاعدة بيانات دقيقة وشاملة:**
  * فهرس كامل لكافة سور القرآن الـ 114 والأجزاء الـ 30 مع أرقام الصفحات في مصحف المدينة، وعدد الآيات، وتصنيف السور (مكية / مدنية).
* **بحث فوري متطور يتجاهل التشكيل (Tashkeel-Insensitive Search):**
  * بحث سلس باللغة العربية (مع التشكيل أو بدونه)، أو بالترجمة والمعنى الإنجليزي، أو بالاسم الصوتي المنقحر (Transliteration)، أو برقم السورة.
* **مستكشف ومعدل الإنجاز المباشر (Direct Progress Inspector):**
  * النقر على أي سورة لتعديل الآيات المحفوظة يدوياً أو تعيين السورة كاملة كمحفوظة بنقرة واحدة.

---

### 6. التنبيهات الذكية وتكامل التقويم (Smart Notifications & Sync)
* **تنبيهات المتصفح الأصلية (Browser Web Notifications API):**
  * طلب الإذن، واختبار الإشعارات مباشرة، وتلقي تنبيهات سطح المكتب والمتصفح المجدولة.
* **نغمة صوتية هادئة مدمجة (Gentle Audio Chime):**
  * توليد نغمة تنبيه لطيفة بدون ملفات صوتية خارجية عبر واجهة المتصفح البرمجية (`Web Audio API`).
* **قواعد الإطلاق والتذكير الذكية:**
  * ⏰ **تذكير ورد الحفظ الجديد اليومي**
  * 🌙 **تذكير ورد المساء للربط والمراجعة**
  * 🔥 **حماية أيام الالتزام (Streak Protection):** تذكير تلقائي في حال عدم تسجيل جلسة خلال اليوم.
  * ⚠️ **تنبيه السور المتأخرة عن المراجعة**
* **أوقات الصلوات وساعات الهدوء (Prayer-Time Presets & Quiet Hours):**
  * أوقات جاهزة للتذكير (بعد الفجر، والعصر، والمغرب، والعشاء) مع تحديد ساعات عدم الإزعاج لمنع الإشعارات ليلاً.
* **تصدير التقويم (.ics Calendar Export):**
  * إنشاء ملف تقويم دوري بصيغة `.ics` متوافق مع Apple Calendar وGoogle Calendar وOutlook لتعمل التنبيهات حتى في حال إغلاق المتصفح.

---

### 7. التصميم وتجربة المستخدم (UI, Themes & RTL/LTR)
* **تبديل سلس بين العربية والإنجليزية:**
  * دعم كامل لاتجاه النصوص من اليمين لليسار (`dir="rtl"`) ومن اليسار لليمين (`dir="ltr"`).
  * صياغة التواريخ محلياً، وخطوط طباعية عربية وإسلامية منتقاة بعناية (*IBM Plex Sans Arabic*, *Amiri*, *Plus Jakarta Sans*, *DM Sans*, وأرقام *IBM Plex Mono* للجداول).
* **المظهر الفاتح والداكن (Dual Theme):**
  * مظهران (Light & Dark) مريحان للعين مع حفظ تفضيل المستخدم في المتصفح.
* **شريط تنقل سفلي للهواتف (`BottomNav`):**
  * تصميم متجاوب للهاتف والحاسوب يتيح الوصول السريع بيد واحدة للأقسام الرئيسية على الشاشات الصغيرة.

---

### 8. العمل بدون إنترنت وتطبيق الويب التقدمي (Offline-First PWA & Backup)
* **تطبيق ويب تقدمي قابل للتثبيت (Installable PWA):**
  * يدعم التثبيت كأيقونة تطبيق مستقلة على هواتف **Android** و**iOS** وعلى أنظمة الحاسوب (**Windows / macOS / Linux**) عبر `manifest.webmanifest`.
* **عمل كامل بدون إنترنت (`Service Worker`):**
  * تخزين تلقائي لملفات التطبيق والخطوط (`Google Fonts Cache` + خطوط النظام البديلة) عبر `sw.js` للعمل الفوري عند انقطاع الشبكة، مع شارة توضح حالة الاتصال.
* **حفظ مزدوج محصّن للتقدم (Dual Local Persistence):**
  * مزامنة تلقائية مزدوجة في `localStorage` و`IndexedDB` (`itqan_db_v1`) مع طلب التخزين الدائم (`navigator.storage.persist()`) لمنع مسح البيانات على الهواتف.
* **النسخ الاحتياطي ونقل التقدم (`.json` Export / Import):**
  * تصدير واستيراد ملف `.json` لنقل التقدم والخطط بين الهاتف والحاسوب بسهولة ودون الحاجة لإنترنت أو خادم.
* **البدء النظيف وحذف الجلسات:**
  * إمكانية استكشاف البيانات التجريبية للمعاينة ثم الضغط على **"بدء سجل حفظ جديد فارغ"** للانطلاق من `0%`، مع دعم حذف أي جلسة سُجلت بالخطأ.

## 🚀 البدء والتشغيل | Getting Started

### المتطلبات الأساسية (Prerequisites)
* بيئة تشغيل **Node.js** (الإصدار 20 أو أحدث موصى به).
* مدير الحزم **npm** (أو **pnpm** / **bun**).

### التثبيت والتشغيل المحلي (Installation & Run)

1. **تثبيت الحزم والاعتماديات:**
   ```bash
   npm install
   ```

2. **تشغيل خادم التطوير المحلي:**
   ```bash
   npm run dev
   ```
   *سيعمل التطبيق افتراضياً على العنوان:* `http://localhost:3000`

3. **بناء النسخة الإنتاجية:**
   ```bash
   npm run build
   ```

## 🔒 الخصوصية وحفظ البيانات | Data & Privacy

> [!NOTE]
> **البيانات محفوظة على جهازك بنسبة 100%:**
> جميع الخطط، ومعدلات الإنجاز، وسجلات الجلسات، وتفضيلات التنبيهات والمظهر يتم حفظها محلياً بشكل مزدوج في `localStorage` (تحت المفتاح `itqan_quran_planner_v1`) وفي `IndexedDB` (`itqan_db_v1`) مع طلب التخزين الدائم `navigator.storage.persist()`.
